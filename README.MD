# 罗汉签 · 四端占卜系统

> “暴雨倾盆雷电闪，孤舟逆水浪滔天。进退维艰多险阻，劝君守拙待时迁。” —— 第268签

本项目将传统罗汉签（共500签）数字化，提供 **Web 网页版**、**微信小程序**、**Python 终端版**、**Android APK** 四种使用方式，方便您随时随地求签解惑。

---

## ✨ 功能特性

- ✅ **500签完整数据**：每签包含签诗、总判、15项详细解析（功名、婚姻、求财、疾病、诉讼、行人、年成、求嗣、移居、失物、出行、家宅、六甲、谋望、自身）
- ✅ **随机抽签**：一键随机抽取，诚心求签
- ✅ **按号查询**：输入签号快速查阅任意签文（1-500）
- ✅ **历史记录**：自动保存抽签记录（本地存储）
- ✅ **四端统一**：Web/小程序/Python/Android 共用同一套签文数据库
- ✅ **跨平台支持**：浏览器、手机、电脑均可使用

## 🛠️ 本地运行

### Web 版
cd luohanqian-web
# 直接用浏览器打开 index.html 即可
Python 版
bash
cd luohanqian-python
pip install colorama   # 首次运行需要安装依赖
python luohanqian_divination.py

使用 微信开发者工具 打开 luohanqian-apk/ 目录，填写 AppID 后预览。
